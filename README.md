# Examen #1 - Fundación Patitas Felices

Página web de donaciones desarrollada para la fundación Patitas Felices, cuyo objetivo es concientizar a la comunidad e incentivar la ayuda a través de información de impacto y un formulario de simulación.

## Tecnologías utilizadas
- HTML5 (Estructura semántica)
- CSS3 (Estilos personalizados y diseño responsivo)

## Estructura del proyecto
- `donaciones.html`: Archivo principal de la página.
- `styles.css`: Hoja de estilos con la paleta de colores y diseño visual.
- `/img`: Carpeta que contiene las imágenes del sitio.

## Cómo ver el proyecto
1. Descarga o clona este repositorio en tu computador.
2. Abre la carpeta y haz doble clic en el archivo `donaciones.html`.
3. El proyecto se abrirá automáticamente en tu navegador web de preferencia.
